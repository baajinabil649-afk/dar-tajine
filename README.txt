دار الطاجين - مشروع تعليمي لتطوير موقع مطعم

طريقة التشغيل:
1) افتح index.html في المتصفح.
2) تأكد من اتصال الإنترنت لتحميل خطوط Google Fonts (بقية التصميم يعمل محلياً).
3) جرّب أزرار تصفية الأطباق وقائمة الهاتف ونموذج الحجز.

الملفات:
- index.html: محتوى وهيكل الصفحة.
- style.css: التصميم والألوان والتجاوب مع الهاتف.
- script.js: تصفية الأطباق، قائمة الهاتف، ونموذج الحجز التجريبي.

مهم: دار الطاجين وبياناته وأطباقه وأثمنته نموذج افتراضي للتعلم. نموذج الحجز لا يرسل ولا يخزن أي معلومات. يلزم ربطه بخدمة حقيقية وإضافة بيانات نشاط حقيقي قبل الاستخدام التجاري.
